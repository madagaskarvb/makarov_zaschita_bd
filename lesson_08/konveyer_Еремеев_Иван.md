## Письмо 1. Ревью конвейеров

### 1. Выручка доставленных заказов от ноутбуков.

- Решение: конвейер верный — неверно
- Комментарий: Конвейер достает все доставленный заказы, из этих заказов достает ноутбуки, группирует их и суммирует, все правильн

### 2. Сколько заказов в пути в каждом городе.

- Решение: есть ошибка — $project перед стадией, которой нужно отброшенное поле — верно
- Комментарий: $project отбрасывает поле status, которое нам нужно для следующего шага в конвейере
- Исправленный конвейер:

```js
[{$project: { number: 1, delivery: 1, status: 1} }, { $match: { status: "в пути" } }, {$group: { _id: "$delivery.city", orders: { $sum: 1 } } }, { $sort: { _id: 1 } }]
```

### 3. Номер первого по дате заказа каждого покупателя из трёх: c-007, c-011, c-018.

- Решение: есть ошибка — $first или $last без $sort перед $group — верно
- Комментарий: мы берем первый заказ человека из списка документов, но этот список нужно отсортировать сначала по дате создания заказа
- Исправленный конвейер:

```js
[{ $match: { customer_id: { $in: ["c-007", "c-011", "c-018"] } } }, { $sort: { created: 1} }, { $group: { _id: "$customer_id", first: { $first: "$number" } } }, { $sort: { _id: 1 } }]
```

### 4. Пять самых дорогих доставленных заказов.

- Решение: есть ошибка — стадии стоят не в том порядке: $limit срабатывает раньше отбора — верно
- Комментарий: конвейер сначало сортирует по стоимости заказа, берет первые пять заказов, а только потом проверяет что эти заказы были доставлены, хотя это должно быть первым действием
- Исправленный конвейер:

```js
[{ $match: { status: "доставлен" } }, { $sort: { total: -1 } }, { $limit: 5 },  { $project: { _id: 0, number: 1, total: 1 } }]
```

### 5. Выручка доставленных заказов по способам оплаты.

- Решение: есть ошибка — путь к полю записан без знака $ — верно
- Комментарий: написано в конвейере так _id: "payment.method", но должно быть так _id: "$payment.method"
- Исправленный конвейер:

```js
[{ $match: { status: "доставлен" } },  { $group: { _id: "$payment.method", revenue: { $sum: "$total" } } }]
```

## Письмо 2. Сборка из стадий

### 1. Пять самых дорогих доставленных заказов: только номер и сумма, без _id, от дорогого к дешёвому.

```js
db.orders.aggregate([
  { $match: { status: "доставлен" } },
  { $sort: { total: -1 } },
  { $limit: 5 },
  { $project: { _id: 0, number: 1, total: 1 } }
])
```

- Решено, запусков: 1

### 2. Выручка доставленных заказов по городам: поле revenue, города по убыванию выручки.

```js
db.orders.aggregate([
  { $match: { status: "доставлен" } },
  { $group: { _id: "$delivery.city", revenue: { $sum: "$total" } } },
  { $sort: { revenue: -1 } }
])
```

- Решено, запусков: 1

### 3. Сколько штук товаров каждой категории продано в доставленных заказах: поле qty, категории по убыванию qty.

```js
db.orders.aggregate([
  { $match: { status: "доставлен" } },
  { $unwind: "$items" },
  { $group: { _id: "$items.category", qty: { $sum: "$items.qty" } } },
  { $sort: { qty: -1 } }
])
```

- Решено, запусков: 3

### 4. Доставленные заказы по суммам чека: корзины до 50 000, от 50 000 до 200 000 и от 200 000 до 500 000, в каждой — число заказов в поле count.

```js
db.orders.aggregate([
  { $match: { status: "доставлен" } },
  { $bucket: { groupBy: "$total", boundaries: [0, 50000, 200000, 500000] } }
])
```

- Решено, запусков: 5

### 5. Для каждого города — номер и сумма самого дорогого доставленного заказа (поля number и total), города по убыванию total.

```js
db.orders.aggregate([
  { $match: { status: "доставлен" } },
  { $sort: { total: -1 } },
  { $group: { _id: "$delivery.city", number: { $first: "$number" }, total: { $first: "$total" } } }
])
```

- Решено, запусков: 1
